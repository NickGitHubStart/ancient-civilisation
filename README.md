# Great Year

Interaktive 3D-Simulation der Präzession, wie Graham Hancock sie in *Fingerprints of the Gods* beschreibt.

```
npm install
npm run dev
```

Ziehen an der Zeitleiste, um durch die Jahrtausende zu gehen. **Zeitalter** hält die Erde am Frühlingsanfang, damit der goldene Zeiger das Sternbild der Epoche trifft. **Jahr** lässt die Erde umlaufen — der Zeiger wandert vorwärts durch die Sternbilder.

A, B, C leuchten, wenn Bahn, Achse und Nord-Sommer die ungünstige Eiszeit-Stellung erreichen.
